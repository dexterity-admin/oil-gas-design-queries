Starter library
===============
Documents placed in this folder ship inside the DexMentor Library installer.
The first time the Library starts on the server PC they are copied into its
"Starter library" shelf and indexed, so engineers get answers straight away,
before the librarian has added the office's own standards.

Accepted: PDF, Word (.docx), Excel (.xlsx, .xlsm), PowerPoint (.pptx).
A starter document the librarian deletes from the Library desk stays deleted.
Only put documents here that the company is allowed to hand out.
